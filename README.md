A golden koi leaps out of the teacup into the stars. One image, made to get make.fun's AI judge excited: a colossal golden koi bursting out of a blue-and-white porcelain teacup into a deep indigo starry sky, a tiny paper boat riding on its back, water exploding in golden light. Impossible scale, one clear focal shape, frozen mid-leap — awe first, surprise second, momentum all the way through.

The program is a byte copy: `main.py` copies `entry.png` to `/output/entry.png`, so both of the grader's runs write the same bytes. The image is a JPEG (1024×683, 282,054 bytes, under the 1 MiB cap), named `entry.png` as the rules allow — the gate tells a PNG from a JPEG by its first bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
