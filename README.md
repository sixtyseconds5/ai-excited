A golden koi leaps out of a porcelain teacup into a starry night sky, a tiny
paper boat riding on its back. The picture is painted pixel by pixel by
`main.py` — no image library, no downloaded assets, just the Python standard
library: a night-sky gradient, two hundred and forty scattered stars, a
crescent moon, steam curling up from the tea and dissolving into stars, and
the koi arcing from the cup's rim toward the water, gold on top and cream
along its belly, scales, fins and a flowing double tail.

## Run it

```sh
python3 main.py
```

That writes `entry.png` (1024x683) next to the script. The output is
deterministic — run it twice and the bytes are identical.
